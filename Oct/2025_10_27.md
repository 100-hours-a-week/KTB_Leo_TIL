## 오늘의 내용

## CNN

FCN에 넣기위해 flatten하기 전에 이미지의 공간 정보 소실을 해결하기 위해 만들어진 모델입니다.

## Pooling

Feature map의 크기를 줄이고 중요한 정보를 추려내는데 활용됩니다

### max pooling

이미지나 feature map에서 뚜렷하게 나타나는 패턴을 강조하는데 유리하며 작은 노이즈나 위치 변동의 영향을줄일수있습니다

주로 이미지 분류나 object detection같은 작업에서 자주 활용됩니다

### average pooling

구역 전체의 통계적 특성을 고르게 반영할 수 있으며 극단적으로 큰 값이 존재하더라도 이를 완화해 전체 분포를 안정적으로 유지합니다

노이즈나 이상치를 상쇄할 수있고 모델출력이 급격하게 변동하는 것 방지합니다

Pooling 사용이유

- 계산량 감소
    - 입력 데이터(feature map)의 크기를 줄여 연산량을 크게 낮춤
    - 메모리 사용량도 감소
- 불변성 확보
    - 위치 변동, scaling, 회전등에 대해 특징을 유지할 수 있도록 함
    - max pooling 같은 경우 작은 위치 이동에 영향을 덜 받음
- 과적합 방지
    - 데이터 차원을 줄이고, 정보를 뭉뚱그려 표현하여 모델 복잡도를 낮춤
    - 전체 파라미터 수가 줄어든다
- 중요한 특징 추출
    - 노이즈나 세부 변동을 제거
    - 엣지, 경계등 핵심 패턴을 부각
    - 분류나 인식 작업에 유리

## Flatten layer

Flatten Layer는 다차원 데이터(4D[ Batch, Height, Width, Channels])를 Conv, MaxPooling레이어를 거쳐 2D 텐서([Batch, Features])로 변환하여, 각 샘플을 1차원 벡터로 만들어 Fully Connected(Dense) Layer에 입력할 수 있도록 합니다.

이때 FCL에 입력은 펴진 1차원 벡터(이미지)하나이지만 batch처리를 통하여 병렬처리를 하는 것입니다.

## Pre-trained Model

이미 훈련을 마친 모델로 학습 시간을 절약 시켜주고, 더 나은 성능을 기대할 수 있으며, 소규모 데이터셋에서도 좋은 성능을 내여 데이터 부족을 극복할 수 있습니다.

**원-핫 인코딩**

- 사용 이유
    - 분류문제에서 출력 레이블을 신경망 모델이 이해할 수 있는 형태로 변환하기 위해 사용
    - 클래스 10개인 경우 각 레이블은 10차원 벡터로 표현
    - 손실함수를 사용할때 예측 확률과 실제 레이블 간의 차이를 계산하기 위해
- softmax 같은 함수를 출력층에서 사용하면 확률을 출력하는데 이 확률분포와 실제 레이블(원핫인코딩된 벡터)간의 차이를 최소화하는것이 모델학습의 목표입니다.

## ResNet

**ex) ResNet-50**: 50개 레이어

- 사용 이유
    - Residual connections를 이용하여 기울기 소실 문제를 해결하였기 때문에
- 단점
    - Skip connection을 저장하여야 하기에 메모리 사용량이 많다

## VGG

**ex) VGG-16**: 16개 레이어 (13개 conv + 3개 FC)

- 사용 이유
    - 이해하기 쉬운 구조로 공부하기 좋다
    - 전이학습에 효과적이다
- 단점
    - 과적합 위험이 크다
    - 파라미터가 약 138M개로 너무 많다
