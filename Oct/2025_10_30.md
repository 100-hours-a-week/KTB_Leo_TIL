## Hyperparameter란?

파라미터와 다르게 사용자의 입력값이고 모델마다 정해진 최적의 값이 없습니다. 따라서 휴리스틱 방식 또는 알고리즘을 사용하여 최적의 값을 찾아야합니다.

### 네트워크와 관련된 Hyperparameters

- 은닉층의 뉴런 개수
- Dropout
- Weight Initialization

### 학습에 사용되는 Hyperparameters

- 학습률
- 모멘텀
- Epoch
- 배치 사이즈
- Optimizer
- 정규화 파라미터

이외에도 다양한 hyperparameter가 존재하며 모델마다 존재하는 것들도 있습니다.

## Hyperparameter Tuning

Hyperparameter의 최적값을 찾기 위한 방법입니다. 


🤔 이런게 왜 필요해?


Hyperparameter는 모델의 성능을 좌지우지 할 수 있는데 논문을 기준으로 값을 똑같이 가져다 쓰거나 무지성으로 조금씩 바꿔나가도 되지만 우리의 시간과 돈은 소중합니다.

따라서 여러가지 최적화 기법들을 통해 효율적으로 최적의 값을 찾기위해 사용합니다.

### Random Search

경계 내에서 임의의 조합을 추출하여 최적의 조합을 찾는 방법입니다.

적은 수의 hyperparameter가 모델 성능의 영향을 미치는 경우에 좋은 결과를 낼 수 있다고 합니다.

<img width="103" height="110" alt="스크린샷 2025-10-30 오후 7 02 49" src="https://github.com/user-attachments/assets/ec84e69d-6d4f-4259-be52-47f95627a10f" />

```python
from sklearn.model_selection import RandomizedSearchCV

random_search = {'criterion': ['entropy', 'gini'],
               'max_depth': [2],
               'max_features': ['auto', 'sqrt'],
               'min_samples_leaf': [4, 6, 8],
               'min_samples_split': [5, 7,10],
               'n_estimators': [20]}
               
model = RandomizedSearchCV(estimator = clf, param_distributions = random_search, n_iter = 10, 
                               cv = 4, verbose= 1, random_state= 101, n_jobs = -1)
```

### Grid Search

주어진 값 내에서 적용할 수 있는 모든 조합의 hyperparameter를 사용하여 최적의 값을 탐색하는 방법입니다

차이점은 Random Search가 탐색할 범위를 갖고 범위내의 임의의 조합을 찾는 반면에 Grid Search는 탐색할 값이 주어지고 모든 조합을 탐색합니다.

<img width="96" height="107" alt="스크린샷 2025-10-30 오후 7 02 58" src="https://github.com/user-attachments/assets/4690fa6c-a195-4e91-9c9e-d55560a8b0d1" />

```python
from sklearn.model_selection import GridSearchCV

grid_search = {'criterion': ['entropy', 'gini'],
               'max_depth': [2],
               'max_features': ['auto', 'sqrt'],
               'min_samples_leaf': [4, 6, 8],
               'min_samples_split': [5, 7,10],
               'n_estimators': [20]}

clf = RandomForestClassifier()
model = GridSearchCV(estimator = clf, param_grid = grid_search, cv = 4, verbose= 5, n_jobs = -1)
```

### Bayesian Optimization

베이지안 최적화는 목적함수를 최대 또는 최소로 하는 최적해를 찾는 방법입니다.

- surrogate model : 목적함수에 대한 확률적인 추정을 하는 모델
- acquisition function : surrogate model이 추정한결과를 바탕으로 다음 입력데이터(하이퍼파라미터 조합)을 정하는 함수

<img width="174" height="58" alt="스크린샷 2025-10-30 오후 7 05 01" src="https://github.com/user-attachments/assets/21e4e3fc-ce84-4784-ba6f-d3804646cc42" />

SVM같이 조건부 관계에 있는 hyperparameter에 대해 효과적이라고 합니다.

Bayesian Opitmization 같은 경우는 라이브러리도 존재하지만 HyperOpt라는 자동화 프레임워크를 주로 사용한다고 합니다.

```python
from hyperopt import hp, fmin, tpe, STATUS_OK, Trials

# space: 알고리즘이 탐색할 범위를 정의한다. 
# hp.choice: 리스트 내의 값을 무작위로 추출
# hp.uniform: 정의된 범위 내에서 임의의 숫자를 무작위 추출
# hp.quniform: 정의된 범위 내에서 마지막 숫자만큼의 간격을 두어 숫자를 추출 
space = {'criterion': hp.choice('criterion', ['entropy', 'gini']),
        'max_depth': hp.quniform('max_depth', 10, 12, 10),
        'max_features': hp.choice('max_features', ['auto', 'sqrt','log2', None]),
        'min_samples_leaf': hp.uniform ('min_samples_leaf', 0, 0.5),
        'min_samples_split' : hp.uniform ('min_samples_split', 0, 1),
        'n_estimators' : hp.choice('n_estimators', [10, 50])
    }

def objective(space):
    hopt = RandomForestClassifier(criterion = space['criterion'], 
                                   max_depth = space['max_depth'],
                                 max_features = space['max_features'],
                                 min_samples_leaf = space['min_samples_leaf'],
                                 min_samples_split = space['min_samples_split'],
                                 n_estimators = space['n_estimators'], 
                                 )
```

### Hyper Band

연속 분할 알고리즘을 통해 제한된 시간에서 최적의 hyperparameter 구성을 찾는 방법입니다.

<img width="132" height="83" alt="스크린샷 2025-10-30 오후 7 07 20" src="https://github.com/user-attachments/assets/e0ad07c5-59a5-4647-9999-2a5b5dd0b413" />

SHA 알고리즘은 주어진 자원 내에서 학습 중간의 손실을 기반으로 성능이 좋지 않은 hyperparameter를 반복적으로 제거해나갑니다.

<img width="171" height="88" alt="스크린샷 2025-10-30 오후 7 09 01" src="https://github.com/user-attachments/assets/6f83a59f-62ce-4d8c-bb5d-546e30661c5d" />

Hyper Band는 자원과 step마다 비율을 정해주면 random으로 n과 B를 여러개 만들어 여러번의 SHA를 실행하여 찾습니다.

추가적으로 Optuna라는 자동화 프레임워크가 존재하는데 HyperOpt보다 많이 쓰이면서 다음과 같은 장점들을 갖고 있습니다

- 넓은 범용성
- 최신 동향의 최적화 알고리즘 보유
- 간단한 메소드로 시각화 가능
