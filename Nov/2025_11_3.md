## Transformer 훑어보기

## Seq2Seq 모델의 한계

**Seq2Seq(Sequence-to-Sequence)** 모델은 입력 시퀀스를 받아 출력 시퀀스를 생성하는 구조로, 번역이나 요약 같은 작업에서 많이 사용되었습니다.

하지만 구조적인 제약이 뚜렷했습니다.

### 🔹 1) Bottleneck 문제

Seq2Seq는 입력 시퀀스 전체를 **고정된 크기의 context vector** 하나에 압축합니다.

즉, 긴 문장일수록 초반의 정보가 손실되기 쉽고, 이는 곧 성능 저하로 이어집니다.

### 🔹 2) Long-term Dependency

LSTM, GRU가 장기 의존성 문제를 완화했지만 완전히 해결하지는 못했습니다.

시퀀스가 길어질수록 앞쪽 단어와 뒤쪽 단어의 관계를 학습하기가 어렵습니다.

### 🔹 3) 병렬 처리 불가능

RNN 구조는 **순차적 처리**만 가능하기 때문에 병렬 학습이 불가능합니다.

`t`시점 출력을 계산하기 전에 반드시 `t-1`시점 계산이 완료되어야 하죠.

### 🔹 4) 기울기 소실 / 폭발

긴 시퀀스를 처리하는 과정에서 **vanishing / exploding gradient** 문제가 여전히 발생합니다.

이런 한계들을 해결하기 위해 등장한 것이 바로 **Attention 메커니즘**입니다.

---

## Attention 메커니즘 — “필요할 때 필요한 정보에 집중하자”

기존 RNN은 문장 전체를 하나의 벡터로 압축했지만, **Attention**은 “모든 단어의 정보를 동적으로 참조하자”는 아이디어입니다.

### 🧠 Attention의 핵심 개념

Decoder가 출력을 생성할 때마다 Encoder의 모든 hidden state를 참고해, **현재 시점에 어떤 단어가 중요한지**를 계산합니다.

### 계산 과정

1. **Score 계산**
    
    Decoder hidden state와 각 Encoder hidden state의 유사도 계산
    
    `score(h_t, h_s) = h_t^T W h_s`
    
2. **Attention Weights 계산**
    
    softmax로 확률 분포로 변환
    
    `α_ts = exp(score(h_t, h_s)) / Σ exp(score(h_t, h_s'))`
    
3. **Context Vector 계산**
    
    가중치로 weighted sum 계산
    
    `c_t = Σ α_ts * h_s`
    

### 장점

- 긴 문장에서도 **관련 부분만 선택적 집중**
- 정보 손실 없이 **동적 접근 가능**
- Attention weights 시각화로 **모델 해석 가능**

하지만 RNN 기반이라는 점에서 **병렬화 문제**는 여전히 남았습니다.

이 문제를 완벽히 해결한 것이 바로 **Transformer**입니다.

---

## Embedding — 단어를 숫자로 표현하기

텍스트는 숫자가 아니므로, 컴퓨터가 이해하려면 단어를 벡터로 바꿔야 합니다.

하지만 **one-hot encoding**은 단어 간 의미 관계를 반영하지 못하고 차원이 지나치게 큽니다.

### 💡 Word Embedding

Embedding은 단어를 고정된 차원(예: 512)의 **dense vector**로 변환하여, 의미가 유사한 단어들이 공간상에서 가까이 위치하도록 합니다.

Transformer에서는 다음과 같이 표현합니다:

`E ∈ R^(vocab_size × d_model)`

또한 positional encoding과 균형을 맞추기 위해 **√d_model로 스케일링**을 적용합니다.

---

## Positional Encoding — 순서를 알려주는 좌표계

Transformer는 순차적으로 데이터를 처리하지 않기 때문에 **단어의 순서 정보가 사라집니다.**

이를 해결하기 위해 각 단어 벡터에 **위치 정보를 수학적으로 더해줍니다.**

---

## Transformer 구조 — Encoder & Decoder

Transformer는 크게 **Encoder**와 **Decoder**로 구성되며, 각각 동일한 구조의 레이어를 여러 번(N=6) 쌓은 형태입니다.

### 🔸 Encoder

- **Multi-Head Self-Attention**: 입력 문장 내 단어들 간의 관계 학습
- **Feed Forward Network**: 각 단어 표현을 개별적으로 변환
- **Residual Connection + LayerNorm** 적용

### 🔸 Decoder

- **Masked Multi-Head Self-Attention**: 미래 단어 정보 차단
- **Encoder-Decoder Attention (Cross-Attention)**: 입력 문장의 어느 부분에 집중할지 결정
- **Feed Forward Network + LayerNorm**

### 정보 흐름

1. 입력 문장 → Embedding + Positional Encoding
2. Encoder 스택 통과
3. Encoder 출력이 Decoder의 cross-attention 입력으로 사용
4. Decoder 스택 통과
5. Linear + Softmax → 최종 예측 단어 생성

---

## Multi-Head Attention — 다양한 시점에서의 집중

### 🔹 Self-Attention

각 단어는 Query(Q), Key(K), Value(V)로 변환됩니다.

```
Q = XW^Q
K = XW^K
V = XW^V
```

이후 **Scaled Dot-Product Attention**으로 유사도를 계산합니다.

```
Attention(Q, K, V) = softmax(QK^T / √d_k) V

```

### 🔹 Multi-Head의 아이디어

단일 attention으로는 다양한 관계를 동시에 학습하기 어렵습니다.

따라서 여러 개의 head(보통 8개)를 병렬로 사용합니다.

```
MultiHead(Q, K, V) = Concat(head₁, ..., headₕ)W^O

```

각 head는 서로 다른 가중치를 사용해 **다양한 관계(구문, 의미 등)** 를 학습합니다.

### 장점

- 여러 관점에서 문맥 관계 포착
- 표현력 향상
- 완전 병렬 처리 가능

---

## Position-wise Feed Forward Network

Self-Attention 뒤에는 각 단어별로 독립적인 FFN이 적용됩니다.

```
FFN(x) = ReLU(xW₁ + b₁)W₂ + b₂

```

- 입력/출력 차원: d_model (512)
- 중간 차원: d_ff (보통 2048)

### 역할

- **비선형성 추가**로 표현력 향상
- **각 단어의 표현 자체 변환**
- **차원 확장**으로 복잡한 변환 가능

사실상 “1D convolution(kernel=1)”과 동일한 효과를 가집니다.

---

## Layer Normalization — 안정적인 학습의 비결

### 🔸 왜 필요한가?

딥러닝 모델이 깊어질수록 **내부 공변량 이동** 문제가 발생합니다.

Normalization은 이를 완화하고 학습 안정성을 높여줍니다
